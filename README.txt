BAPU NO TRADER - PWA PACKAGE (DEMO ONLY)
=============================================
Files (badhi ek j folder ma, koi sub-folder nahi):
  index.html     - full app (demo data, paper trading, capital setting, TradingView button)
  manifest.json  - app info (name, icons, colors)
  sw.js          - offline support
  icon-192.png   - app icon
  icon-512.png   - app icon (motu)

IMPORTANT: files na naam badalvana nathi. Upload karti vakhte Files -> Downloads
ma thi pasand karo (Gallery/Recent ma thi nahi), nahito naam random thai jashe.

STEP 1 - HOST KARO (GitHub Pages)
  1. github.com -> New repository -> Public
  2. Add file -> Upload files -> aa 5 files (README.txt optional)
  3. Commit changes
  4. Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save
  5. 1-2 minute pachi: https://USERNAME.github.io/REPO-NAME/

STEP 2 - CHECK
  Link khulya pachi dark dashboard dekhay che? Link ni aakhre /manifest.json
  lakhine kholo - text dekhay to barabar.

STEP 3 - APK BANAVO
  1. pwabuilder.com -> link paste -> Start
  2. Package for stores -> Android
  3. Name: BAPU NO TRADER, Package ID: com.bapu.notrader -> Generate
  4. Zip download -> unzip -> .apk phone ma install (Install unknown apps allow)
  Signing key file sambhali ne rakhjo.

NOTE: Aa app demo che. Real broker, real order ke API key nathi.
